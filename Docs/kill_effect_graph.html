The whole idea

Pick a class from Effect Classes that is not the one on the gun right now, then hand it to Set Effect Class.

Hover a node to light up only the wires that touch it (click pins it there). Scroll to zoom, drag to pan.

Worked example

Pool [Basic, Ricochet, Heavy, Jammed], live = Basic, roll r in 0..3:

Plain Random Integer in Range(0..3) would keep the same effect 1 kill in 4 — the player reads that as “the feature is broken”. That is the only reason for the Find / Equal / Add / Percent / Select detour.

Build order (11 steps)
  1. Drag Effect Classes into the graph → Get Effect Classes.
  2. From its array output → Length.
  3. From Length → Subtract, set B = 1.
  4. From Subtract → Random Integer in Range (lands on Max), leave Min = 0.
  5. From the array output again → Find Item; wire Effect Class (singular) into Item To Find.
  6. From the roll → Equal (int); wire Find's Index into the other pin.
  7. From the roll → Add (int), B = 1 → into Percent; wire Length into B.
  8. From the Equal bool output → Select (it then arrives as Condition / True / False).
  9. Roll → False; Percent → True.
  10. Array output → Get (a copy); Select → its Index.
  11. Get (a copy) class output → Set Effect Class's New Effect Class.

Step 8 is the one that bites: connect the bool first, or you get an Index / Option 0 / Option 1 node and have to fight the pin type.
